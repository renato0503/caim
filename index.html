E se você pudesse abrir
uma IDE real no Safari?

O CAIM é uma Progressive Web App. Você adiciona à tela inicial do iPhone. Abre rápido. Funciona offline. Fecha o browser. Abre de novo. Tudo ainda lá.

🎮

É um app. Mas não é um app.

PWA instalável no iOS. Zero App Store. Zero aprovação. Abra o Safari, adicione à tela inicial, pronto. O ícone fica na home como qualquer app nativo.

🔐

Suas chaves. Suas regras.

DeepSeek, Qwen, OpenAI — você conecta suas próprias chaves. Elas ficam cifradas no seu dispositivo (AES-GCM via Web Crypto). Nunca passam por servidor nosso.

📶

Funciona no avião.

Service Worker + IndexedDB. Uma vez carregado, o CAIM funciona sem internet. Editar, commitar, revisar diffs — tudo local. Só precisa de rede para a LLM ou o push.

Do prompt ao deploy em 4 passos.

1

Abra e configure ~2min

Adicione à tela inicial. Faça login. Conecte suas chaves de LLM no Settings (DeepSeek, Qwen ou OpenAI).

2

Peça em português ~30s

No chat: "Crie uma landing page para minha padaria". O agente usa suas chaves e gera os arquivos na sua frente.

3

Revise o Diff ~1min

Cada arquivo aparece no Diff Viewer. Aceite ou rejeite cada bloco. Você decide o que vai para o VFS.

4

Deploy com um clique ~2min

Clique em "Deploy". Seu código vira uma página pública em owner.github.io/seu-mvp. A URL fica salva no seu dashboard.

E não é pra você se...

  • ❌ Você trabalha em projetos enterprise monolíticos. CAIM é para MVPs, protótipos e scripts. Times grandes ainda precisam de VS Code + desktop.
  • ❌ Você precisa de colaboração em tempo real. Não há (ainda) cursor compartilhado nem review em equipe. É uma ferramenta solo.
  • ❌ Você não tem chaves de API de LLM. O CAIM não fornece LLMs. Você precisa ter (ou criar) conta em DeepSeek, Qwen ou OpenAI. Os custos são pagos direto aos provedores.
  • ❌ Você usa Android como principal. Otimizamos para iOS Safari. Funciona no Android Chrome, mas a experiência não é validada lá.
  • ❌ Você quer substituir seu IDE desktop. O CAIM complementa seu setup. É para quando o PC não está perto.

Perguntas que você deveria fazer.

É grátis?

O CAIM é gratuito. Mas você paga pelas chaves de LLM que usar. DeepSeek é o mais barato — ~$0.27 por 1M tokens de input.

Meu código é enviado pra vocês?

Não. O código fica no IndexedDB do seu dispositivo. Só vai pra LLM quando você pede geração, e só pro GitHub quando você faz deploy.

Posso usar o Claude/Gemini?

Hoje: DeepSeek, Qwen e OpenAI-compatible. Claude e Gemini estão no roadmap, mas ainda não implementados.

E se eu perder meu celular?

Seu código fica no IndexedDB local. Se você não fez push para o GitHub, perde. Por isso o CAIM incentiva commits frequentes.

Funciona offline de verdade?

Sim, para editar, commitar e revisar diffs. Só precisa de internet para: (a) chamar a LLM, (b) fazer push, (c) carregar a primeira vez.

Por que o deploy é na conta do Owner?

Limitação do GitHub API + CORS. Para você ter seu próprio repo, precisaria fornecer seu PAT — e não pedimos isso. O deploy cria um repo na conta do Owner e você recebe a URL pública.

É open source?

Sim. O código está no GitHub (github.com/renato0503/caim). Você pode auditar, forkar e self-host se quiser.

Posso contribuir?

Sim. Issues e PRs são bem-vindos. É vanilla JS + Vite, sem framework lock-in.

Por que não tem na App Store?

A Apple é restritiva com IDEs que executam código. Como PWA, o CAIM não precisa de aprovação. Basta adicionar à tela inicial.

Vai ter versão desktop?

O foco é mobile-first. Mas por ser PWA, funciona em qualquer navegador desktop — é só abrir caim.web.app.

Pronto para codar no bolso?

Abra no Safari do seu iPhone. Adicione à tela inicial. Configure suas chaves. Comece em 2 minutos.
