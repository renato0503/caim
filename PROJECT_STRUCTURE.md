# CAIM (Cerra AI Mobile) - Project Structure

This document outlines the intended file structure for the CAIM project.

## Root Level
- `index.html` - Main PWA entry point (mobile-optimized app shell)
- `manifest.json` - PWA manifest for iOS/Android home screen installation
- `sw.js` - Service Worker for offline caching and PWA functionality
- `firebase.json` - Firebase Hosting configuration
- `.gitignore` - Git ignore rules

## Source Structure (`src/`)
- `src/js/`
  - `app.js` - Main application entry point and UI wiring
  - `vfs-service.js` - Virtual File System abstraction over IndexedDB
  - `git-service.js` - isomorphic-git wrapper for in-browser Git operations
  - `diff-viewer.js` - Mobile-friendly diff viewer component
  - `agent-manager.js` - Central orchestrator for AI agent drivers
  - `drivers/`
    - `base-agent.js` - BaseAgent interface/contract
    - `cline-driver.js` - Cline XML-based tool call parser
    - `opencode-driver.js` - OpenCode standard tool call parser
    - `kilocode-driver.js` - Kilo Code specific parser
- `src/css/`
  - `main.css` - Global mobile-first styles

## Assets (`assets/`)
- `assets/icons/`
  - `icon-192.png` - 192x192 PWA icon
  - `icon-512.png` - 512x512 PWA icon

## Build Output (`public/`) - Generated by build tool
- Static assets served by Firebase Hosting
- Minified JS/CSS bundles

## Planned Architecture
1. VFS Layer: Dexie.js/IndexedDB backed virtual file system
2. Agent Layer: Multiple AI agent drivers with tool execution capabilities
3. Git Layer: isomorphic-git + lightning-fs for in-browser Git
4. UI Layer: CodeMirror 6 editor, chat interface, diff viewer
